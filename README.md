## ESS - V2

Este projeto é a reconstrução de uma loja online de papelaria que desenvolvi no início da minha carreira, quando eu tinha pouca experiência e pouco conhecimento técnico.

Na V2, a ideia é refazer tudo do zero, com um novo design, um backend de verdade e todas as funcionalidades necessárias para o sistema funcionar como uma loja completa.

Também é um bom case de estudo e uma forma de desenvolver minhas habilidades, já que dá para comparar o que eu fazia antes com o que sei hoje.
